# StopWatch 显示设计 v3

打开 `display.html` 可预览正常输入、闲置、断连、配对、低电量、USB 挂起和全部五层。
这是交互设计稿；不连接设备，不修改固件。所有数值均是演示数据。
第三版布局已确认并同步到固件：中等尺寸、动图下移、电量条调整并下移、WPM 下移。实机效果待刷入验证。输入和闲置动画均可离线使用，下方候选动图从 GitHub 在线加载。

用户已反馈当前实验固件能够正常输入，并于 2026-09-27 确认仅降至 100 kHz 后屏幕画面正常；
其他异常场景与长期稳定性仍需逐项验证。

## 布局

以 466 × 466 圆形 AMOLED 为坐标系，黑底，浅灰文字，淡绿连接状态，橙色异常。
关键文字远离圆屏边缘，不使用环形文字或需要旋转观看的信息。

| 区域 | 位置 / 尺寸（约 px） | 内容 |
|---|---|---|
| USB 状态 | y40，居中，13 px 字 | READY / SUSPENDED / NOT CONNECTED |
| 左右电量 | 左 x61–112 / 右 x354–405，y150–360 | 百分比在上方，细竖条从底部填充，不显示左右手文字，以位置区分 |
| 月薪喵 | 默认 x112，y150，242 × 214 | 保持原图比例；可比较 205 × 182、242 × 214、261 × 233 三档 |
| 当前层 | y374，居中，28 px | 仅显示层名 BASE / NUM / NAV / FN / SYMBOL / SCROLL / SNIPE |
| 提示 | y412，居中，14 px | USB 状态、旋钮短暂提示 |

不在主屏显示 RSSI、连接间隔、包计数或推测的毫秒延迟。
第二版 HTML 在 USB 状态与动图之间加入 WPM（当前 y104，居中），不移动其他屏幕元素。
速度滑块为演示数据；输入/低电量场景显示设定值，其他场景演示为 0，固件已接入最近 10 秒的可打印 HID 按键统计，每 5 个字符折算为一词，停止文字输入 3 秒归零。
Ctrl/Alt/GUI 组合、方向键、媒体键和旋钮不计；Shift 字符计入。不统计主机自动重复、输入法候选或真实文本内容。Caps Lock 必须来自 USB 主机 LED 输出，
不能仅凭按了 Caps 键就猜测状态。

## 状态规则

- 始终保留层名称；断连、配对、低电量和输入/闲置不显示底部文字。
- 配对窗口逻辑保持原样，但不在底部显示倒计时。
- 电量未知显示 `--%`，真实零电量显示 `0%`；断连显示“未连接”，不展示旧值为实时值。
- 少于 20% 提醒；可用 25% 作为退出提醒的回差阈值。USB 是否充电不可仅由电量推断。
- 输入激活工作动画，3 秒无键盘按下切回睡觉；60 秒无操作降亮度至约 20%，120 秒关闭显示并停止动画刷新。
- 正常默认亮度约 35%，电脑 USB 挂起立即息屏；按键/旋钮操作或 USB 恢复后亮屏，不依赖触摸。
- 左右身份应从已知物理位置或可靠元数据识别并绑定到 BLE 身份地址。
  连接槽位 0 / 1 不等于左 / 右。未识别时显示“待识别”，不编造方向。
- 旋钮事件可短暂显示“音量 + / −”或“向下 / 上滚动”；没有主机反馈时不显示绝对音量百分比。
- 可选后续操作：黄键切页面、蓝键切亮度。清除配对不放在单击操作中。

## 当前固件实现

`main/display.c` 使用 LVGL 9.2.2，`main/display_hw.c` 使用 CO5300 2.1.0。
屏幕任务优先级 1，与输入任务分开；状态以短临界区快照传递。
显示初始化或传输失败时停止显示任务，BLE/USB 继续工作。

- 按官方 StopWatch 初始化序列配置 QSPI、IOE 屏幕供电和复位；不更改 M5PM1 充电设置或 USB 复用。
- 电量通过可选 BAS（0x180F / 0x2A19）连接后读取，每 30 秒轮询；不支持或读取失败时显示未知。
- 通过项目全局键位或旋钮编号识别左右，按 BLE 身份在 RAM 中保留到本次关机。
  重启后需要两侧各按一键；不依赖连接先后顺序。
- 显示全部五层；底部五个圆点对应 L0–L4。未知电量、低电量回差、闲置和 USB 挂起采用上文规则。
- 242 × 214 RGB565 动画从 Flash 直接读取，按原 GIF 帧时长播放；内部 DMA 缓冲约 15 KiB，四向转正使用 PSRAM 画布。
- 中文提示使用 Noto Sans SC 的小字库，资源版权和重新生成方法见
  [资源说明](../main/assets/README.md)。常规编译不需要图片或字库转换工具。

面板初始化依据 [M5Stack 官方显示实现](https://github.com/m5stack/M5StopWatch-UserDemo/blob/main/main/hal/hal_display.cpp)
及 [IO 扩展实现](https://github.com/m5stack/M5IOE1)。实机显示已获用户确认；
IOE 启动修正与验证记录见 [固件说明](../README.md#屏幕初始化速率)。

## 接入原则

1. 在独立显示任务中初始化 M5IOE1 屏幕供电和复位、CO5300 QSPI，先画固定布局。
2. 从键位引擎和 USB / BLE 状态发布轻量快照，显示任务读取。显示失败不阻止 USB/BLE 启动。
3. 接入层、连接、输入活跃状态；真实数据尚未接入的字段保持未知。
4. 添加 Battery Service（0x180F）电量读取/订阅，处理未知、断连和左右身份匹配。
5. 加入月薪喵帧和降亮度；预览用原 GIF，实机另行生成尺寸适配的资源。

全帧动画沿用 40/80 ms 帧时长，按变化区域更新。单帧 466² RGB565 约 424 KiB，
200² RGB565 约 78 KiB。可在启用并验证 PSRAM 后存放图像，SPI DMA 使用合适的
内部 DMA 缓冲分块传输。不要在 USB 输出或 NimBLE 回调中解码图片、刷新屏幕或等待 SPI。

## 重力自动转正预览与实验固件

HTML 加入 -180°～180° 机身角度滑块、常用角度按钮、自动转正开关和平放状态。
外壳的橙色刻度标识机身顶部；屏幕全部元素作为整体反向旋转，保持现实中的竖直方向。
平放时冻结最后有效的“相对机身补偿角度”，并不会继续锁定现实朝向；
此时再绕桌面法线旋转机身，文字也会跟随机身转动。恢复竖放后重新计算补偿。
这是目标交互演示，不访问真实传感器，也不模拟滤波、抖动或固件性能。
第三版布局、动画和 WPM 保留；休眠场景展示黑屏。用户已确认，固件已接入 BMI270 与 PSRAM 整屏旋转，安装轴方向及实际帧率待实机验证。

界面微调：动画、层名、电量条和 WPM 统一下移 10 px。正常输入/闲置不显示文字提示；
后续下移及提示规则以文末再次微调为准。

再次微调：上述四组元素再下移 10 px。断连、首次配对/身份识别、低电量也不显示底部提示；
两侧电量区域仍显示连接状态与低电量颜色。剩余 USB/旋钮提示位于 y412，层指示点位于 y428（单独向上调整 10 px）。

## 全帧动画与四向转正

固件保留本地 GIF 全部帧：输入 21 帧 / 880 ms，睡眠 35 帧 / 1640 ms，逐帧沿用 40/80 ms 时长。
动画调度独立于 100 ms 状态栏更新。重力只切换 0/90/180/270 度，带 10 度边界滞回与 300 ms 稳定等待；平放保持最后方向。
0 度直接拷贝，其他方向用整数像素索引，不再逐像素计算任意角度旋转。HTML 同步四向目标效果。
全帧 RGB565 约 5.8 MB；16 MB Flash 的 factory 分区由 4 MB 扩为 8 MB，起始地址和 NVS 不变。
首次升级务必使用完整 `idf.py -p COMx flash`，同时更新分区表和应用；不要仅刷应用 bin。无需擦除 NVS 或重新配对。
帧资源和时长与 GIF 一致；实际显示帧率仍受屏幕传输耗时影响，需实机验证。

当前动图尺寸调整为 180 × 180，中心保持 (233, 257)，左上角为 (143, 167)。全帧与原始时长不变，其余界面元素位置不变；全帧 RGB565 资源合计 3,628,800 字节，保留现有 8 MB 应用分区。
