# Dongle 竖屏界面

当前屏幕按 64×128 排版，物理 SH1106 仍使用 128×64 驱动参数。
逻辑画面顺时针旋转 90° 后写入屏幕，因此将原先横向可读的设备逆时针转 90° 即可正向阅读。
无需修改接线或清除配对。

| 区域 | 内容 |
|---|---|
| 顶部 | USB / 蓝牙输出状态、蓝牙配置编号 |
| 电量 | 上行固定 `L`，下行固定 `R`，百分比与电池图标 |
| 中部 | 32×32 月薪喵，10 帧/秒 |
| 动画下方 | 当前层名；长层名滚动 |
| 底部 | Caps / Num / Scroll Lock 状态、四个修饰键图标 |

未识别左右来源或尚未收到电量时显示 `L  --%` / `R  --%`。每次 dongle 启动后，
左右各按一次普通按键；电量上报与按键到达顺序均不影响最终结果。
不根据蓝牙配对顺序猜测左右，0% 不会隐藏文字。
可选的 dongle 自身电量会增加 `D` 行；可选 WPM 数字放在小猫右侧，默认不启用。

动画规则：默认播放 idle；第一次实际按下键后，在下一次显示处理时切换到 error。
每次新的按下事件都会将恢复时间推迟到 3 秒后；松键、系统长按重复和旋钮旋转不延长时间。
两种动画均循环播放，同一状态内重复按键不重启动画。屏幕原有的空闲熄屏策略保留。

## 实机验证

只刷新的 `cornix_dongle_nosd.uf2`，不需要 reset 或重刷左右手。

1. 启动时能看到完整 L/R 文字与占位读数。两边各按一次普通键后确认各自电量。
2. 点按一次立即进入 active/error 动画；停止后约 3 秒恢复 idle。
3. 在第 3 秒到来前再次按键，确认恢复时间延长；持续输入不反复重启动画。
4. 检查 Base、Num/Nav、Fn/Symbol、Ctrl/Shift/Alt/Win 和 Caps Lock，确保文字、图标不裁切。
5. 检查冷启动、空闲熄屏后唤醒、快速输入和重连，观察有无花屏或遗留像素。

## 实现与自动检查

旧电池组件在自动宽度容器中，把文本放到图标左边的负坐标位置，文字会被父容器裁切。
现在父容器固定为 64 像素宽，文本和图标都有明确的非负坐标。

Zephyr 4.1 的 SH1106 驱动不提供 90° 旋转；仅设置 LVGL rotation 不会旋转其单色传输。
本模块将每个脏矩形从 LVGL I1 转为旋转后的 SH1106 页数据，保留局部刷新、像素极性和原有
400 kHz TWIM 设置。转换使用固定 1 KiB 缓冲区，只在显示线程同步写屏。

GitHub Actions 在固件构建之外运行 battery、cat、portrait 三组测试，覆盖文字边界、
反向配对顺序、未知及 0% 电量、合并更新、首次按键、3 秒边界、长时间运行，以及整屏/局部
旋转、两种单色极性、行填充、越界和写屏错误。自动测试不能代替以上实机显示检查。
